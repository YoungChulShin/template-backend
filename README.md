# template-backend

## 개요

이 저장소는 백엔드 템플릿을 여러 언어·프레임워크로 구현한다. 모든 구현은 [도메인 정의](docs/domain.md)의 샘플 도메인을 똑같이 구현해, 스택 간 비교와 재사용이 가능하도록 한다.

샘플 도메인은 **상품·주문**이다. 선정 이유는 다음과 같다.

- 누구나 설명 없이 이해할 수 있다.
- 도메인이 3개(회원, 상품, 주문)로 작다.
- 실무 백엔드에서 반복되는 문제를 자연스럽게 담는다.
  - DB 저장
  - 하위 엔티티를 가진 애그리거트 (주문 ─< 주문항목)
  - 상태 전이 (주문 생명주기)
  - 동시성 (재고 차감)
  - 외부 연동 (알림톡·문자 발송, dummy 구현)

용어는 [용어사전](docs/glossary.md)을 따른다.

### 범위 밖

- 결제
- 배송 추적, 배송 업체 연동
- 장바구니, 쿠폰, 할인
- 부분 취소, 반품
- 관리자 권한 구분
- 로그인과 인증
