# 용어사전

모든 구현은 아래 영문 용어를 클래스·필드·상태값 이름에 그대로 사용한다.

## 도메인

| 한글 | 영문 | 뜻 |
|---|---|---|
| 회원 | Member | 상품을 주문하는 사람 |
| 상품 | Product | 판매하는 물건 |
| 주문 | Order | 회원이 하나 이상의 상품을 한 번에 구매하는 것 |
| 주문항목 | OrderItem | 주문에 속한 상품 한 줄 (상품, 주문 가격, 수량) |
| 알림 | Notification | 회원에게 보내는 알림톡·문자 |

## 속성

| 한글 | 영문 | 뜻 |
|---|---|---|
| 휴대폰 번호 | phoneNumber | 회원의 알림 수신 번호 |
| 가격 | price | 상품 1개당 판매 가격 |
| 재고 수량 | stockQuantity | 상품의 판매 가능 수량 |
| 주문 가격 | orderPrice | 주문 시점에 고정된 상품 가격 |
| 수량 | quantity | 주문항목의 주문 개수 |
| 항목 금액 | itemAmount | 주문 가격 × 수량 |
| 주문 총액 | totalAmount | 주문항목 금액의 합 |

## 상태

| 한글 | 영문 | 뜻 |
|---|---|---|
| 판매 중 | ON_SALE | 주문 가능한 상품 |
| 판매 중지 | STOPPED | 주문할 수 없는 상품 |
| 주문 완료 | ORDERED | 주문이 생성되고 재고가 차감된 상태 |
| 배송 중 | SHIPPING | 발송된 상태. 취소할 수 없다 |
| 배송 완료 | DELIVERED | 고객에게 도착한 상태 |
| 취소 | CANCELED | 주문이 취소되고 재고가 복원된 상태 |

## 행위

| 한글 | 영문 | 뜻 |
|---|---|---|
| 주문하다 | place | 주문을 생성한다 |
| 취소하다 | cancel | 주문을 취소한다 |
| 발송하다 | ship | 주문을 배송 중으로 바꾼다 |
| 배송 완료하다 | deliver | 주문을 배송 완료로 바꾼다 |
| 재고를 차감하다 | decreaseStock | 주문 수량만큼 재고를 줄인다 |
| 재고를 복원하다 | increaseStock | 취소 수량만큼 재고를 되돌린다 |

## 행위자

| 한글 | 영문 | 뜻 |
|---|---|---|
| 고객 | Customer | 가입한 회원으로서 주문하는 사용자 |
| 운영자 | Operator | 상품을 관리하고 발송·배송 완료를 처리하는 사용자. 권한 구분은 범위 밖 |

## 알림 수단

| 한글 | 영문 | 뜻 |
|---|---|---|
| 알림톡 | AlimTalk | 카카오 알림톡 |
| 문자 | SMS | 휴대폰 문자 메시지 |

## 설계 용어

| 한글 | 영문 | 뜻 |
|---|---|---|
| 애그리거트 | Aggregate | 함께 생성·변경·삭제되는 도메인 객체 묶음. 일관성을 지키는 단위 |
| 애그리거트 루트 | Aggregate Root | 애그리거트의 대표 객체. 외부는 루트를 통해서만 애그리거트에 접근한다 |
